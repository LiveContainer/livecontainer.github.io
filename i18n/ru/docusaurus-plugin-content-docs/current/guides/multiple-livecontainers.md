# Несколько экземпляров LiveContainer {#multiple-livecontainers}

Несколько экземпляров LiveContainer позволяют одновременно запускать разные приложения с *почти* незаметным переносом данных между экземплярами и использовать доступные слоты бесплатной учётной записи.

## Установка ещё одного LiveContainer {#install-another-livecontainer}

Откройте `Settings → Install Another LiveContainer`.

Здесь можно подготовить и установить дополнительные экземпляры, например `LiveContainer2` и `LiveContainer3`.

## Установка {#installation}
Нажмите «LiveContainer2» или «LiveContainer3», чтобы установить или переустановить дополнительный экземпляр. LiveContainer создаст для него IPA-файл. Откройте этот файл в AltStore/SideStore для установки либо сохраните его для дальнейшей настройки.

Если нужен игровой режим, перед установкой включите «Set Category as Game» и «Allow Game Mode».

## Проверка состояния установки {#verify-installation-status}

На странице нескольких экземпляров LiveContainer:

- галочка означает, что другой экземпляр установлен и обнаружен;
- крестик означает, что он не обнаружен или не установлен.

## Использование приложений в разных экземплярах {#use-apps-across-livecontainers}

1. В основном LiveContainer с синим значком удерживайте карточку приложения → Settings → Convert to Shared App.
2. Заново откройте другие экземпляры LiveContainer с серым значком. Теперь общее приложение можно запускать и из них.

## Распределение запуска между экземплярами {#about-app-dispatching}
Выбор экземпляра LiveContainer зависит от способа запуска приложения:

- При использовании схемы URL или App Clip сначала всегда открывается основной LiveContainer с синим значком. Если нужное приложение уже работает в другом экземпляре, произойдёт переключение в него. В противном случае LiveContainer попробует найти свободный экземпляр и переключиться в него.
- При использовании команды Launch App выбор происходит в фоне, и открывается только выбранный свободный экземпляр LiveContainer.

Если все экземпляры заняты, появится предложение открыть приложение во втором или третьем LiveContainer с серым значком либо завершить текущее приложение и запустить нужное в основном.

## Частые ошибки {#common-pitfalls}
- Приложение не видно в других экземплярах LiveContainer: оно не переведено в общее приложение.
