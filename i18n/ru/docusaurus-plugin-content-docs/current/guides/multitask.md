# Многозадачность {#multitask}

LiveContainer поддерживает режим многозадачности: можно держать несколько приложений или контейнеров активными и быстро переключаться между ними.

## Требования {#requirements}

1. iOS/iPadOS 16.0+.
2. При установке LiveContainer сохраните расширения приложения: выберите `Keep App Extensions` в SideStore/AltStore.

Если расширения отсутствуют, запуск в режиме многозадачности может завершиться ошибкой `LiveProcess extension not found`.

## Запуск в режиме многозадачности {#start-multitask}

1. Переведите нужное приложение в `Shared App` в его настройках, если оно ещё не общее.
2. Удерживайте карточку приложения.
3. Нажмите `Multitask`.

Можно включить `Auto Launch in Multitask Mode` в настройках. Тогда основная кнопка `Run` будет сразу запускать приложение в режиме многозадачности.

## Режимы многозадачности {#multitask-modes}
Доступны на iPadOS 16.1+.

В текущих сборках в разделе `Settings → Multitask` доступны два режима:

1. `Virtual Window`: плавающие окна внутри приложения, док-панель, режим «Картинка в картинке» (PiP), разворачивание и сворачивание окон.
2. `Native Window`: каждое приложение открывается в отдельном системном окне; требуется iPadOS 16.1+.

## Настройки многозадачности {#multitask-settings}

В разделе `Settings → Multitask` доступны:

- `Multitask Mode`: выбор между `Virtual Window` и `Native Window`.
- `Auto Launch in Multitask Mode`: запускать приложения в режиме многозадачности по умолчанию при нажатии `Run`.

При выборе `Virtual Window` появляются дополнительные настройки:

- `Launch Multitask Maximized`: открывать новые окна развёрнутыми.
- `Only One App on Stage`: автоматически сворачивать остальные окна при разворачивании одного приложения.
- `Auto End PiP`: автоматически завершать сеанс PiP при возвращении к окну приложения.
- `Skip Terminated Screen`: сразу закрывать окно после выхода из приложения, не показывая экран завершения.
- `Restart Terminated App`: вместе с `Skip Terminated Screen` автоматически перезапускать приложение после завершения.
- `Bottom Window Bar`: размещать панель управления окном внизу экрана.
- `Redirect URL to Host`: передавать поддерживаемые схемы URL основному LiveContainer вместо дочернего процесса, чтобы повысить надёжность переходов между приложениями.
- `Dock Width`: ширина док-панели многозадачности.

## Поведение контейнеров {#container-behavior}

- Каждый экземпляр в режиме многозадачности связан с контейнером.
- При запуске уже работающего контейнера LiveContainer выводит существующее окно на передний план вместо создания копии.
- При попытке обычного запуска, пока работают приложения в режиме многозадачности, LiveContainer запросит подтверждение.

## JIT в режиме многозадачности {#jit-with-multitask}

Если для приложения включено `Launch with JIT`, сначала будет включён JIT, а затем откроется окно многозадачности.

Для большей стабильности используйте средство включения JIT с поддержкой подключения к процессу по PID, например StikDebug.
Это рекомендуемый способ совместного использования JIT и многозадачности.
