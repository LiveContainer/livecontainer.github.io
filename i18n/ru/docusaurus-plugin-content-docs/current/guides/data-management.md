# Управление данными {#data-management}

## Очистка неиспользуемых папок данных {#clean-unused-data-folders}

:::note
Это действие доступно только в основном экземпляре LiveContainer.
:::

Удаляет локальные папки данных, на которые больше не ссылается ни один контейнер приложения.

## Перенос папки App Group {#move-app-group-folder}

:::note
Это действие доступно только в основном экземпляре LiveContainer.
:::

- `Move AppGroup from private to shared`
- `Move AppGroup from shared to private`

Эти действия переносят файлы App Group между частной и общей областями. Если целевая область не пуста, перенос блокируется.

## Перенос неиспользуемых общих папок {#move-dangling-shared-folders}

:::note
Это действие доступно только в основном экземпляре LiveContainer.
:::

Возвращает неиспользуемые общие ресурсы в частную область:

- общие папки данных, которые не используются общими приложениями;
- общие папки твиков, которые не используются общими приложениями, кроме `TweakLoader.dylib`.

Полезно после прерванного переноса данных или переустановки.

## Очистка связки ключей {#clean-keychain}

Удаляет записи связки ключей (`GenericPassword`, `InternetPassword`, `Certificate`, `Key`, `Identity`) в текущей области доступа.
Используйте осторожно: операция затрагивает много данных и может привести к выходу из учётных записей приложений.

## Очистка кеша значков {#clear-icon-cache}

Очищает кеш значков для текущего загруженного списка приложений.

## Инструменты работы с путями {#path-tools}

Используйте их для ручного просмотра файлов или получения точных путей при диагностике.

- `Copy ... Path`: копирует полный путь к `App Group Container`, `Container` или `LiveContainer Bundle` в буфер обмена.
- `Open in Filza`: доступно, только если Filza установлен в LiveContainer; открывает выбранную папку непосредственно в Filza.
