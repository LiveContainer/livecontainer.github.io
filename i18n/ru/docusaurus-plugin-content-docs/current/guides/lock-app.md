# Блокировка и скрытие приложений {#lock--hide-apps}

LiveContainer предлагает три уровня скрытия приложений:

* Блокировка: в настройках отдельного приложения можно включить запрос Face ID или пароля перед запуском.
* Скрытие заблокированных приложений: после блокировки приложение можно скрыть. Оно будет отображаться как заглушка в разделе «Hidden Apps», а для просмотра или запуска потребуется аутентификация.
* Строгий режим скрытия: для полного скрытия включите «Strict Hiding Mode» в настройках LiveContainer после аутентификации. Скрытые приложения исчезнут из интерфейса. Чтобы получить к ним доступ после повторного запуска LiveContainer, трижды нажмите текст «x Apps in total» на главном экране и пройдите аутентификацию.
