# Источники {#sources}

Вкладка `Sources` позволяет просматривать источники в формате AltStore и устанавливать из них приложения напрямую.

## Добавление источника {#add-a-source}

1. Нажмите плюс (`+`).
2. Введите URL источника.
3. Подтвердите добавление.

## Добавление по ссылке {#deep-link-support}

Источники можно добавлять с помощью специальной ссылки:

- `livecontainer://source?url=<encoded_source_url>`

При открытии такой ссылки LiveContainer переключается на вкладку `Sources` и пытается добавить указанный URL источника.

## Удаление и обновление источника {#remove-or-refresh-a-source}

- Используйте меню источника (`...`) или действия смахивания в списке источников.
- `Refresh` обновляет один источник.
- `Refresh All` обновляет все добавленные источники.

## Установка приложения из источника {#install-app-from-a-source}

1. Разверните раздел источника.
2. Найдите приложение и нажмите `Install`.
3. LiveContainer переключится на вкладку `Apps` и начнёт установку по ссылке загрузки последней версии приложения.

:::note
Если в источнике больше 50 приложений, используйте кнопку поиска, чтобы найти нужное. Это ограничение связано с производительностью.
:::

## Частые проблемы {#common-issues}

- **Invalid URL**: неверный формат URL источника.
- **Duplicate source**: такой URL уже добавлен.
- **Unable to refresh source**: проблема с сетью, сервером или форматом JSON.
- **No apps available**: источник прочитан, но список приложений пуст.
