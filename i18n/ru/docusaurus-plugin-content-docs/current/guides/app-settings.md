# Настройки приложения {#app-settings}

Чтобы открыть настройки приложения, удерживайте его карточку в LiveContainer и нажмите `Settings`.

## Данные {#data-section}

- **Bundle Folder**: имя файла пакета приложения.
- **Remark**: ваша заметка об этом приложении.
- **Tweak Folder**:
  - для частного приложения можно выбрать папку твиков;
  - для общего приложения поле на этой странице доступно только для чтения.
- **Convert to Shared App**: перенос пакета приложения, его данных и твиков в общую папку для использования несколькими экземплярами LiveContainer.
- **Convert to Private App**: перенос общего приложения, его данных и твиков обратно в частную папку.

## Контейнеры {#container-section}

- **Container list**: откройте контейнер из списка для управления его настройками.
- **Select Unused Container**: подключение существующих неиспользуемых папок контейнеров; доступно только для частных приложений.

Подробнее см. в разделе [«Несколько и внешние контейнеры»](./containers-and-external-data.md).

## Запуск и JIT {#launchjit-section}

- **Launch with JIT**: запускать это приложение только после включения JIT.
- **JIT Launch Script** (iOS 26+): выбрать пользовательский скрипт запуска с JIT для этого приложения.

## Конфиденциальность {#privacy-section}

- **Lock App**: требовать аутентификацию перед запуском.
- **Hide App**: скрыть приложение из обычного списка; доступно после его блокировки.

## Язык {#language-section}

- Можно задать язык отдельно для приложения.
- `Auto` использует системные настройки или стандартное поведение приложения.

## Исправления {#fixes-section}

- **Fix File Picker**: исправление выбора файлов.
- **Fix Local Notification**: исправление локальных уведомлений.
- **Use LiveContainer's Bundle ID**: использовать идентификатор пакета LiveContainer.

## Ориентация {#orientation-section}
При проблемах с разрешением, особенно в играх с горизонтальной ориентацией, попробуйте включить эту настройку.

- Блокировка ориентации: выключена / горизонтальная / вертикальная.

## Совместимость во время выполнения {#runtime-compatibility-section}
Эти настройки могут помочь обойти проверку внедрения кода в некоторых приложениях.

- **Hide LiveContainer from Dyld API**: скрыть LiveContainer от API dyld.
- **Don't Inject TweakLoader**: не внедрять TweakLoader.
- **Don't Load TweakLoader**: не загружать TweakLoader; появляется после отключения внедрения.

## Поведение SDK {#sdk-behavior-section}

- **Spoof SDK Version**: согласовать поведение системных библиотек с версией SDK приложения.

## Устаревшее исправление выбора файлов {#legacy-file-picker-section}

- **Fix File Picker (legacy)**: старый способ исправления выбора файлов. Выбранные файлы принудительно копируются в папку Inbox приложения. Их можно найти и удалить в контейнере приложения → Inbox. При выборе папок исправление может не работать или приводить к сбою.

## Подпись {#signing-section}

- **Force Sign**: принудительно переподписать приложение сейчас.
- Если для приложения отключена подпись, сначала появится запрос на её повторное включение.
