# Использование твиков {#using-tweaks}

LiveContainer позволяет загружать твики без предварительного внедрения в приложение. Однако прямое внедрение по-прежнему рекомендуется: не все твики корректно работают с TweakLoader в LiveContainer.

LiveContainer включает собственный TweakLoader, который автоматически загружает Ellekit и твики. TweakLoader внедряется в каждое добавленное приложение. При желании можно заменить символическую ссылку `TweakLoader.dylib` собственной реализацией.

## Порядок загрузки {#how-loading-works}

При запуске приложения с включённым TweakLoader компоненты загружаются в следующем порядке:

1. CydiaSubstrate (Ellekit).
2. Глобальные твики из корневой папки `Tweaks`.
3. Твики из выбранной папки конкретного приложения, включая вложенные папки.

LiveContainer поддерживает импорт:

1. `.dylib`
2. `.framework`

## Глобальные твики и твики отдельных приложений {#global-vs-app-specific-tweaks}

| Тип | Куда поместить файлы | Область действия |
| --- | --- | --- |
| Глобальный твик | Корневая папка `Tweaks` | Загружается для всех приложений |
| Твик отдельного приложения | Подпапка внутри `Tweaks` | Загружается только для приложений, у которых выбрана эта папка |

:::note
Управление твиками доступно только в основном LiveContainer с синим значком и для частных приложений. Чтобы добавить твики общему приложению, сначала переведите его в частное. После настройки можно вернуть общий режим — твики продолжат работать.
:::

Чтобы назначить отдельную папку приложению:

1. Откройте вкладку `Tweaks`.
2. Создайте папку.
3. Импортируйте в неё твики.
4. В настройках приложения выберите эту папку в поле `Tweak Folder`.

Для общих приложений поле `Tweak Folder` доступно только для чтения. При необходимости временно переведите приложение в частное, настройте папку твиков и верните общий режим.

## Управление твиками {#managing-tweaks}

1. Импорт: вкладка `Tweaks` → `+` → `Import Tweak`.
2. Создание папки: вкладка `Tweaks` → `+` → `New Folder`.
3. Переименование: удерживайте элемент → `Rename`.
4. Удаление: смахните элемент влево → `Delete`.

## Подпись твиков {#tweak-signing}

Перед загрузкой твики должны быть подписаны.

LiveContainer делает это автоматически перед запуском приложения:

1. Проверяет файлы твиков и существующие записи в `TweakInfo.plist`.
2. Переподписывает изменённые файлы, а также файлы с недействительной или просроченной подписью.
3. Обновляет `TweakInfo.plist` после подписи.

Можно также принудительно переподписать твики кнопкой `Sign` на вкладке `Tweaks`.

## Связанные настройки приложения {#related-app-settings}

На поведение твиков влияют следующие параметры:

1. `Don't Inject TweakLoader`: не добавлять команды загрузки загрузчика при изменении и подписи приложения.
2. `Don't Load TweakLoader`: дополнительно пропускать загрузку во время выполнения; доступно вместе с первым параметром.

Если включены оба параметра, для этого приложения не загружается ни один твик, включая сам `TweakLoader.dylib`.

## Решение проблем {#troubleshooting}

1. Твики не работают в одном приложении: проверьте, что правильно выбрана папка `Tweak Folder` и в настройках не отключён TweakLoader.
2. Твики не работают ни в одном приложении: убедитесь, что глобальные твики добавлены в корневую папку `Tweaks` и подписаны.
3. Не загружается твик в формате framework: убедитесь, что пакет содержит корректный `Info.plist` и `CFBundleExecutable`.
4. Твик не работает после настройки: попробуйте прямое внедрение, поскольку совместимость может различаться.
5. Ошибка Invalid Signature: возможно, нужно вручную переподписать твики.
