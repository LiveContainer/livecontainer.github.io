# Установка {#installation}
:::warning
Используйте только официальные сборки LiveContainer с открытым исходным кодом. Сторонние сборки с закрытым кодом могут получить доступ ко всем данным внутри контейнеров, включая конфиденциальные учётные данные.
:::

:::warning
Следующие средства установки **не поддерживаются**. **Не используйте** их для установки LiveContainer: Sideloadly, i4/3u Tools, NB Tool и большинство онлайн-сервисов подписи.

Другие инструменты могут установить LiveContainer корректно, но мы рекомендуем настраивать его по этому руководству.
:::

## Выбор версии {#choose-a-version}

| Версия | [Отдельный LiveContainer](./installation/standalone.md) | [LiveContainer + SideStore](./installation/lc_sidestore.md) |
| --- | --- | --- |
| Состав | Только приложение LiveContainer | LiveContainer со встроенным SideStore |
| Использование слотов бесплатной учётной записи | 1 слот для LiveContainer и 1 слот для средства установки на устройстве | 1 слот вместе со встроенным SideStore |

## Требования {#requirements}

- iOS/iPadOS 15+
- iOS/iPadOS 16.0+ для многозадачности
- AltStore 2.2.1+ или SideStore 0.6.2+ для отдельного LiveContainer

## Рекомендуемый порядок действий {#recommended-order}

1. Выберите версию из таблицы выше.
2. Следуйте руководству по установке.
3. Импортируйте сертификат для подписи в режиме без JIT.
4. Проверьте настройку на странице диагностики режима без JIT.
