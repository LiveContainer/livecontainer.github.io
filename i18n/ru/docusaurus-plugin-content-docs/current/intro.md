# Введение в LiveContainer {#livecontainer-introduction}

Средство запуска приложений iOS без их фактической установки в систему!

- LiveContainer позволяет запускать приложения iOS внутри себя. Это не эмулятор и не гипервизор.
- Можно добавлять неограниченное число приложений: ограничения бесплатной учётной записи разработчика на 3 приложения и 10 App ID здесь не действуют. Также можно использовать несколько версий одного приложения с отдельными контейнерами данных.
- На iOS 18 и ниже при доступном JIT проверка подписи полностью обходится, поэтому подписывать приложения перед добавлением не нужно. В остальных случаях приложения подписываются тем же сертификатом, что и LiveContainer.

## Возможности {#features}

- Запуск приложений iOS в изолированных контейнерах
- Работа без джейлбрейка
- Удобное управление приложениями
- Несколько контейнеров для одного приложения
- Многозадачность
- Несколько экземпляров LiveContainer
